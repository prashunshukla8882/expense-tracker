## 🎯 About The Project

**ExpenseFlow** is a comprehensive personal finance management application designed to help you track expenses, manage budgets, monitor borrowed/lent money, plan future purchases, and take notes - all in one beautiful, intuitive interface.

### Why ExpenseFlow?

Managing personal finances can be overwhelming. ExpenseFlow simplifies this by providing:

- 📊 **Visual Analytics** - Understand your spending patterns at a glance
- 🎯 **Budget Tracking** - Set and monitor spending limits by category
- 💸 **Borrow Management** - Never forget who owes you or whom you owe
- 🛒 **Wishlist Planning** - Save towards your goals
- 📝 **Integrated Notes** - Keep financial notes and reminders
- 🔒 **Privacy First** - Your data stays on your device
- 🌙 **Dark Mode** - Easy on the eyes, day or night
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile

## 🚀 Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Edge, Safari)
- Text editor (VS Code recommended)
- Git (for version control)
- GitHub account (for hosting)

### Installation

#### Option 1: Download ZIP

1. Click the green **Code** button above
2. Select **Download ZIP**
3. Extract to your desired location
4. Open `index.html` in a browser

#### Option 2: Clone Repository

````bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/expense-tracker.git

# Navigate to project directory
cd expense-tracker

# Open in VS Code (optional)
code .

# Open index.html in browser
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux
Option 3: Fork & Clone
Click the Fork button (top right)
Clone your forked repository:
bash
git clone https://github.com/YOUR_USERNAME/expense-tracker.git
Configuration
1. Set Your Access Password
Open index.html and find this line (around line 180):

javascript
const CORRECT_PASSWORD = 'MySecretPassword123';  // ← CHANGE THIS!
Change it to your own secure password:

javascript
const CORRECT_PASSWORD = 'YourSecurePassword@2024';
2. Customize Currency (Optional)
Open js/storage.js and modify default settings:

javascript
DEFAULT_SETTINGS: {
    currency: 'USD',           // Change to: EUR, GBP, INR, JPY
    currencySymbol: '$',       // Change to: €, £, ₹, ¥
    userName: 'User',          // Default user name
    theme: 'light',            // 'light' or 'dark'
    // ... other settings
}
3. Add Custom Categories (Optional)
In js/storage.js, modify DEFAULT_CATEGORIES:

javascript
DEFAULT_CATEGORIES: [
    { id: 'custom1', name: 'My Category', icon: 'fa-star', color: '#ff6b6b' },
    // ... add more
]
📖 Usage
Adding a Transaction
Click the "+" button or "Add Transaction"
Select Income or Expense
Enter amount and description
Select a category
Choose the date
Add notes or tags (optional)
Click Save
Setting a Budget
Navigate to Budget page
Click "Add Budget"
Select a category
Enter budget amount
Choose period (Monthly/Weekly)
Click Save
Monitor progress on dashboard
Tracking Borrowed Money
Go to Borrow page
Click "Money Given" or "Money Taken"
Enter person's name
Enter amount and date
Set due date (optional)
Add reason and contact info
Click Save
Record payments as received/paid
Managing Wishlist
Navigate to Future Purchases
Click "Add Item"
Enter item name and price
Set priority and category
Add savings amount (what you've saved so far)
Set target date (optional)
Add product link and image (optional)
Click Save
Update savings as you save more
Creating Notes
Go to Notes page
Click "New Note"
Enter title
Select category and color
Write content using the editor
Add tags (comma-separated)
Check "Pin" if important
Click Save
Exporting Data
Go to Settings
Scroll to Data Management
Click "Export Data"
JSON file downloads automatically
Store safely as backup
Importing Data
Go to Settings
Click "Import Data"
Select your backup JSON file
Data is restored automatically
